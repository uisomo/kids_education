最初のフレームからHook全文「一番の技、どれですか？ 教えてください」を重ね、小窓でハイライト1を再生。比較用のHookは無音4秒です。その間も3／3／4秒の時計は進み、4秒時点のハイライト2の続きから拡大。10秒で本編になります。音声の発話終了同期は未接続です。元動画の既存Hook区間の除去も未接続です。

テンプレート内で同じ静止フレームを繰り返さず、17候補から選びます。ただし短い録画の同一人物なので姿勢が似る場合があります。足先までの全身・横顔は素材にありません。コラージュは人物切り抜きですが、小窓と本編は焼き込み済みの入力動画を使っています。録画の「かくす」設定を全編へ接続したデモではありません。

本番はiPhone端末内のVision／Core Image／Core Graphics／Core Textと単一書き出しで実装する方針です。現在のデモ描画はMacのPython、切り抜きはApple Vision。共通Swift4部品と関連8テストを追加しましたが、アプリの最終合成へ接続する作業と実機性能計測は未実施です。全29案のネイティブ描画完成を示すものではありません。

配色見本は役割色をまとめて変更。彩色パレットはOKLCHの色相回転と共通の色域補正を使用し、無彩色案は暗部インクの色を変更できます。比較用2色のみ表示、動画は元配色。本番ではテンプレートと配色を独立抽選し、再試行中は保持します。

## 最新改訂7：ロゴの鮮やかさ
正式な空手ロゴの不透明・明るい有彩色を測定し、HSV彩度中央値0.973／明度中央値0.988を確認。パステル化の原因だった高いOKLCH明度＋全色共通の彩度圧縮を廃止。有彩色の役割はS=0.90〜0.98、V=0.94〜0.99に固定し、HSV色相だけ全色同角度で抽選。白黒写真・墨色は保持。これは知覚的な明度一定の回転ではなく、ロゴに近い鮮やかさを保つRGB内の配色方式。


3907・3908の最新素材ルール：マスクなしは録画人物の背景切り抜き。マスクありの場合だけ正式キャラを使用する。全身素材不足を理由にマスクなしの人物をキャラへ置換しない。デモはマスクなしの人物に修正済み。

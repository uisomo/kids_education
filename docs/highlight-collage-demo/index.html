第0フレームから元動画の代わりにコラージュを表示し、中央にHook全文を3行同時に表示します。右下は縦1本のハイライトです。確認用にHookを4秒表示し、その間も3／3／4秒の再生は進みます。終了位置から拡大し、10秒で本編へ。テスト動画冒頭の声を使用し、先頭の無音0.2645秒を除いて0秒から再生します。3行は0秒から同時表示し、Hookの終了は確認用の4秒です。コラージュは背景切り抜き、小窓・本編は入力済み録画を使用しており、実際の「かくす」設定との接続は未実施です。共通Swift部品は追加しましたが、本番書き出しへの接続とiPhone実機性能の確認はこれからです。白黒・紙色を保ち、参照の色相差と彩度・明度の序列を維持して明るく調整。色相は共通角度で抽選。Hookは既存の丸ゴシックを維持し、承認済みの1番（普通・黒・淡色）または6番（淡色・黒・普通）を使用。中央は黒、上下は主色と白40％の淡色。組み合わせは動画中固定。装飾英字は日本語、数字は録画日付に置換。配色・乙は静止画のみ。

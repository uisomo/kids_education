## 再生成順

プロジェクト直下で実行する。承認済み動画や本番への接続は行わない。

```sh
python3 tools/highlight-collage-demo/rounded-gallery-v4.py
python3 tools/highlight-collage-demo/fixed-assets-v1.py
python3 tools/highlight-collage-demo/rounded-body-v4.py
python3 tools/highlight-collage-demo/glossy-prototype-v4.py
python3 tools/highlight-collage-demo/review-gallery-v4.py
```

最初のコマンドは全35案の静止画、2番目は新規2案を合成してv4用静止画へ反映、3番目は共通本編の追加表示だけを更新、4番目は動画化とデコード検証、5番目は比較ギャラリーを作る。

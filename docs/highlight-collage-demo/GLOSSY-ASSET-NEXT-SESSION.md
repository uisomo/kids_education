## 背景全体か個別素材かの判断

- 背景全体：背面の固定色面・紙片・区切りの相互関係が重要で、写真/文字を全部抜いても構図が成立する場合。720×1280の正確なレイアウト参照を作る。
- 個別素材：円・星・テープ等が再利用可能、厳密な座標が必要、または写真/文字の前後へ挟む必要がある場合。透明PNGと元の境界/アンカーを保存する。
- 組合せ：共通の背面と、前面の独立素材が必要な場合。背景一枚に前景装飾まで焼き込まない。
- 生成全体がズレたら写真や文字を動かして合わせない。個別素材方式へ切り替えるか、背景を再生成する。

## 見た目と生成ルール

出発点は `glossy-lab/whole-gloss/3900-vivid-layout-reference.png`、`3900-vivid-generated-background.png`、`3900-vivid-composite-art.jpg` と `vivid-prompt.txt`。これは質感の参照であり、全案を3900と同じ形にする指示ではない。

ブランドに合う主色・明部・暗部を先に設定し、その配色を参照にして生成。意図しないパステル化を避ける。3897/3885は単色濃淡の検討例。imagegenスキルを読み、生成には組込みimage_genを使う。生成は文字・数字・写真・人物なし。元の写真と鮮明な文字を後から合成する。文字は丸ゴシック化の方針を引き継ぐが、アセット担当は文字の描画コードを勝手に変更しない。

コード製の艶、疑似反射、ベベル、人物内部の艶は禁止。既存/生成済みアセットの色替えは可。星は尖らせず丸く。全素材を均一な厚い箱にしない。

素材とプロンプト、使用参照、配色、用途、サイズ、アンカー、前後のレイヤー、透過の有無を保存。元写真のcrop・座標・アルファ、文字の位置・回転、前後関係は変更しない。現行の抽出スクリプトは実験であり、人物が生成背景に混入しないか必ず確認する。

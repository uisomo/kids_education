【1. スクリーンショットを差し替えるか → 差し替えるべき（まだ着手していない）】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
判定：差し替えるべき。理由は3つ。

1. 下タブの数が変わった。いまのスクリーンショット（karate/piano とも 01〜06）は
   すべて 2026-09-21〜22 に撮ったもので、当時は下タブが3つだった。いま撮り直すと
   すべての画面に4つ目の「アイテム」タブが写り込む — 見た目が変わってしまっている。
2. 06番（保護者ゲート）の元絵は appstore/karate/screenshots/source/gate.png で、
   これは差しかえ前の「白帯」の絵を撮ったもの。今日 11e1d27 で背景そのものを
   「黒帯」に差しかえたので、06番のスクリーンショットは もう実際の画面と違う。
3. 今回いちばんの目玉である「アイテムタブ・キラキラ・トロフィー」が、
   6枚のどのスクリーンショットにも一度も映っていない。App Store Connect の
   新機能欄には書いても、ストアの見た目（スクリーンショット）に出ていなければ
   ダウンロードする人には伝わらない。

【差し替えの手順（karate・piano とも同じやり方）】
1. シミュレーターで最新ビルドを起動する（iPhone 17 Pro Max・審査用スクショと同じ機種）。
   アイテムタブでキラキラが何本か集まった状態・帯が2〜3色そろった状態を
   あらかじめ作っておく（真っ白なコレクション画面は見栄えがしないため）。
   種を仕込むコツは karate-howto-videos.md の「sim seeding tricks」を参照。
2. 次の画面をスクリーンショットで撮る（本体まるごと、切り取らない）：
   - 01：特訓タブ（録画前の画面）— いまの rec-boy.png / rec-none.png と同じ画面でよい
   - 02：応援中の画面（録画中）— いまの rec-girl.png / rec-icon.png と同じでよい
   - 03：積み重ねタブ（レベル・帯／音符）— いまの strength.png と同じでよい
   - 04：特訓タブのメニュー一覧 — いまの menu.png と同じでよい
   - 05：保存した動画のフレーム — いまの rec-frame.png と同じでよい
   - ★新規：アイテムタブ（キラキラのコレクション・帯が2〜3色そろった状態・
     できればトロフィーが1つ見えている） → 新しいファイル名で保存
     （例：source/items.png）
   - 06：保護者ゲート → 撮り直す（新しい黒帯の絵の画面）→ 同じ名前 source/gate.png に
     上書き（今日差しかえた karate-trainer/public/backgrounds/gate.jpg が背景に出る）
3. slides.json にスライドを1枚足す（アイテムタブを06に、保護者ゲートを07にする案）。
   appstore/karate/screenshots/slides.json と appstore/piano/screenshots/slides.json の
   両方を編集：
     { "file": "06.png", "src": "source/items.png",
       "title": ["集めて、つけて", "動画にも映る"],
       "sub": "キラキラを集めて、帯／音符をコレクション" }
   を今の06番の手前に差し込み、今の06番（保護者ゲート）を07番にする。
   sizes/folders/theme はそのまま変えない。
4. 作り直す：
     swift karate-trainer/tools/make-store-screenshots.swift appstore/karate/screenshots/slides.json
     swift karate-trainer/tools/make-store-screenshots.swift appstore/piano/screenshots/slides.json
   6.9inch/・6.5inch/ に 01〜07.png ができる。目で見て確認してから、
   古い01〜06.pngは screenshots/old-v2/ のような名前で退避する（前例：old-v1/）。
5. App Store Connect のバージョン画面 → スクリーンショット差し替え（6.9インチ・
   6.5インチの両方。6.7インチ以下は「以前と同じ」を選べば自動で引き継がれる）。

【今回やらない場合】：06番だけ撮り直して差し替え、他は前のままでも審査は通る
（見た目の古さだけの問題で、審査で指摘される種類の不備ではない）。
ただしアイテムタブが一度も見えないのは、宣伝としてはもったいない。
